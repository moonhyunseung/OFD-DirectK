# Analysis

Analysis code must consume versioned raw results and must not redefine the experiment after measurement.

Required practice:

- read raw data from a recorded result manifest;
- keep derived tables/figures reproducible from source rows;
- separate measured quantities from inferred explanations;
- report negative/crossover regions, not only wins;
- never use profiler attribution as proof of an algebraic identity.

Notebooks may be exploratory, but durable conclusions should be reproducible from scripts or clearly versioned notebook state.
