# Theory workspace

This directory contains exact K-side mathematics before hardware implementation.

Planned topics:

- decoded-quantized score map;
- offset-binary direct normal form;
- signed-recoded normal form;
- bilinear complexity and its distinction from matrix-rank bounds;
- exact representation transformations;
- symbolic work/intermediate counts;
- lower bounds and non-goals.

Every result must state source/target spaces, assumptions, exact identity or bijection, and what empirical boundary remains unresolved.
